# Working in Idea Development

This repository contains independent projects. Work within the requested project folder.
Read that project's README and any nested AGENTS.md before changing it.

- Keep each project's dependencies, lockfile, configuration and commands independent.
- Do not introduce a root workspace, shared app shell or cross-project imports unless requested.
- Run project commands from the relevant project directory.
- Preserve project behaviour during structural changes.
- Do not commit local credentials, installed dependencies or generated build output.
- Use focused commits that explain the change and its purpose.
